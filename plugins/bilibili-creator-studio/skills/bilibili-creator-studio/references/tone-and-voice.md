# 语气与个人声线

语气不是“严肃/轻松”单选，而是一组可调参数。默认使用 0–4 档，2 为中性。

| 维度 | 0 | 4 |
|---|---|---|
| 温度 | 克制疏离 | 亲近关怀 |
| 能量 | 平静低调 | 高能外放 |
| 幽默 | 几乎无梗 | 高频喜剧化 |
| 锋利度 | 圆润保守 | 直接尖锐 |
| 专业度 | 日常直白 | 术语严谨 |
| 脆弱度 | 只谈对象 | 明显自我暴露 |
| 节奏 | 舒缓留白 | 紧凑快速 |
| 口语化 | 书面规整 | 强口语与碎句 |

可额外指定：方言/地域表达、网络词密度、句长、第一/第二人称比例、反问频率、类比风格、禁用词和隐私边界。

## 校准流程

1. 从用户文字或样稿提取可观察特征，不诊断人格。
2. 写出一份“声线卡”：常用句长、开场习惯、笑点类型、情绪边界、可信度来源、避免事项。
3. 给出 80–150 字试音稿。若有备选，最多三种，且每种改变多个相关参数而不是换几个形容词。
4. 用户确认后再扩写长稿。
5. 完稿后做朗读检查：拗口词、气口、连续长句、重复句式、书面连接词和不像本人会说的话。

## 风格转换规则

- 不改变事实、数字、证据强度和必要限定词。
- 不以模仿在世创作者为目标。把“像某某”翻译为抽象特征，例如冷面、短句、观察型幽默、低能量反差。
- 不用堆网络梗伪装年轻感；梗应服务观点并考虑时效。
- 幽默提高时仍保留论证链；专业度提高时仍保证可听懂。
- 用户没有个人样本时，明确这是暂定声线，发布后用真实反馈迭代。
