# 质量门禁与复盘

## 发布前七项门禁

每项用 `通过 / 需改 / 未知`，不要用模糊总分掩盖致命问题。

1. **承诺一致**：标题、封面、开头和正文是否交付同一价值？
2. **可信**：关键主张是否有来源、演示或明确的个人经验边界？
3. **可懂**：新观众能否理解人物、术语、因果和上下文？
4. **推进**：每个段落是否带来新信息、变化、笑点或决定？
5. **可看**：重要内容是否有对应画面，而非长时间重复“人脸 + 字幕”？
6. **可拍**：素材、地点、授权、预算、安全和时间是否现实？
7. **合规与尊重**：是否涉及当前平台规则、版权、隐私、商业披露或高风险建议？

P0：事实/法律/安全/隐私/授权问题，发布前必须解决。  
P1：承诺不兑现、结构断裂或关键素材缺失，应在拍摄前解决。  
P2：措辞、节奏和视觉增强，可在不影响核心的情况下迭代。

## 桌读 / 纸面剪辑

- 按真实表演速度朗读并计时，不只靠字符数。
- 标记喘不过气、容易念错、听一遍难懂和需要画面才能成立的句子。
- 只听音频一次，再只看画面说明一次：两者应互补，核心信息不能无意丢失。
- 尝试删去 10%；若价值不变，继续删。
- 检查开头是否立即对应标题/封面承诺，而不是先自我介绍或铺垫制作辛苦。

## 发布后复盘

记录数据窗口、流量来源、视频时长、发布时间和样本量。数据不足时只写“早期信号”，不下定论。

- **包装**：曝光到观看行为、搜索词、外部入口；不要只看点击率而忽略流量来源。
- **开头**：早期留存与标题/封面兑现情况。
- **正文**：平段、下降、峰值和重复观看处；峰值也可能表示没听懂。
- **关系**：新/回访观众、关注、评论质量、观众用自己的话复述了什么。
- **价值行为**：收藏、投币、分享、评论等只结合内容目标解释，不假设单一算法权重。
- **生产成本**：研究、拍摄、剪辑耗时，是否可持续。

每次只优先测试一个变量，例如选题角度、封面表达、开头兑现速度、解释顺序或画面类型。保留其他条件，才能形成有意义的学习。
