# 调研与选题验证

只在需要当前趋势、竞品、事实核验或选题池时读取本文件。

## 证据优先级

1. B站官方规则、创作中心、创作学院、官方账号和用户自己的创作中心数据。
2. 主题领域的一手来源：法律法规、论文、标准、公司公告、原始数据、当事人完整陈述。
3. 可靠二手报道或专业机构分析。
4. 平台搜索结果、评论、社区讨论和竞品视频，作为需求与表达信号，不作为事实真伪的最终依据。
5. 通用经验与创作直觉，只能标记为假设。

记录来源标题、URL、发布日期或数据窗口、访问日期、支持的具体主张。热点、价格、政策、榜单、产品参数、人物身份和平台功能均需实时核验。

## 研究步骤

1. 把宽泛主题改写为“受众 + 场景 + 问题/欲望 + 可交付结果”。
2. 列出受众实际会使用的 5–10 个搜索表达，包括口语、误写和问题句。
3. 检查站内创作灵感、搜索联想、近期结果、相关话题和用户自己的历史数据；无法访问时明确缺口。
4. 抽样竞品，而不是只看头部：记录发布时间、角度、承诺、形式、证据、评论需求和内容缺口。不要把播放量当作内容质量的单一代理。
5. 对事实主题先建“主张—证据表”，再写脚本。
6. 形成 3–7 个候选角度，并说明每个角度适合的表达形态。

## 选题卡

对每项使用 `强 / 中 / 弱 / 未知`，并写一句证据。只有在证据可比较时才可换算成数字。

| 维度 | 问题 |
|---|---|
| 受众需求 | 谁会主动点开，具体想解决什么？ |
| 创作者优势 | 为什么由这个用户讲更可信或更有趣？ |
| 新鲜角度 | 相比已有内容增加了什么，而非只换措辞？ |
| 可证实性 | 核心结论能否由来源、演示或真实经历支撑？ |
| 可制作性 | 时间、预算、素材、地点与隐私是否允许？ |
| 系列潜力 | 能否自然产生后续，而不是机械拆分？ |

输出结论只能是：推进、收窄、换角度、暂存、放弃。附一个最小验证实验，例如先写 30 秒开场、发布动态问卷、检查历史搜索流量或做低成本短稿。不要承诺流量。

## 主张—证据表

| ID | 脚本主张 | 类型 | 来源/经历 | 置信度 | 限定词或待核验项 |
|---|---|---|---|---|---|
| F01 | … | 事实 / 估算 / 观点 / 个人经历 | … | 高 / 中 / 低 | … |

高风险主张必须回到一手来源。存在争议时呈现边界与主要反例，不把相关性说成因果，不把单一个案说成普遍规律。

## 研究输出

- 一句话机会判断。
- 受众与观看场景。
- 证据摘要与空白。
- 候选角度及其权衡。
- 推荐角度、拒绝角度及理由。
- 后续研究或最小验证动作。
