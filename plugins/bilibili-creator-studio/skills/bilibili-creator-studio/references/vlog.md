# Vlog

Vlog 的价值来自“经历中的变化”，不是素材的时间顺序本身。

## 先确认故事发动机

- 我想做成什么、去哪里、找到什么、验证什么或熬过什么？
- 为什么今天/这次值得记录？
- 什么会阻碍目标？
- 创作者在结尾知道、感受或选择了什么不同的东西？
- 观众除了围观，还能获得何种体验、判断或信息？

如果没有目标、变化或独特观察，建议改为主题散文、教程、清单或知识口播，而不是强行称为 Vlog。

## 推荐叙事骨架

1. **冷开场**：最能代表结果、矛盾或情绪的一瞬，不虚构因果。
2. **起点**：今天要做什么、为什么在意、限制是什么。
3. **推进**：选择和行动推动故事，环境细节建立现场感。
4. **摩擦**：真实意外、成本、错误或犹豫；若没有，不要编造。
5. **转折**：新信息、决定或情绪变化改变后续行动。
6. **结果**：展示实际结果，包括不完整或失败。
7. **反思**：从经历提炼具体认识，不强行宏大升华。

## 三层脚本

- **可预写**：开场说明、背景、必要知识、转场旁白、结尾反思草案。
- **捕捉目标**：地点建立、关键动作、反应、过程细节、环境声、必要特写和安全备份镜头。
- **不可预写**：真实对话、意外、当下反应。只定义观察目标，不写成必然发生的台词。

## 真实性规则

- 补拍或重演必须在成片语境中不造成“实时抓拍”的误导；重要时明确说明。
- 未经同意不暴露他人隐私、敏感地点或未成年人信息。
- 不为冲突驱动危险行为，不把受伤、违法或骚扰当作内容机制。
- 不把品牌安排伪装成纯偶遇；商业合作按当前规则披露。

## 拍摄清单按功能组织

- 定位：全景、路标、时间、天气、环境声。
- 行动：开始、过程、阻碍、决定、结果。
- 关系：眼神、对话、等待、空间距离。
- 细节：手、物件、屏幕、票据、痕迹、前后对比。
- 反应：当下感受和事后反思分开记录。
- 备份：每个关键动作至少有一个可剪接的进入/离开或细节镜头。

纸面预览要标出缺失素材与替代方案，不假定尚未拍到的情节一定存在。
