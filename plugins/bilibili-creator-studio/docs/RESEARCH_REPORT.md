# B站创作 SOP 调研与设计结论

调研日期：2026-09-19

## 对原 Skill 的审计

原文件适合作为入门清单：它已有选题、结构、互动、制作备忘和完整输出模板。但存在五个主要缺口：

1. 把“平台算法偏好”“最佳时长”“三分钟高潮”等经验写成普遍事实，没有来源和适用边界。
2. 用星级评估实时热度与竞品密度，却明确不依赖实时数据，容易制造虚假精确性。
3. 以分区决定结构，无法处理同一题材在知识口播、Vlog、脱口秀之间的表达选择。
4. 交付停在大纲，没有完整逐字稿、音画预览、事实台账、用户确认门禁和发布后复盘。
5. 强制弹幕点和三连话术，容易把互动设计降为机械诱导，而非真实讨论价值。

## 可靠来源中的共识

- B站官方“创作灵感”把近期热门选题、优质作品和未来事件作为选题参考；这支持研究站内信号，但不证明热点一定适合每个账号。
- B站官方扶持案例强调创作者自身优势、素材筛选、情绪变化、时长与字数规划；案例应作为可试验经验，而非算法定律。
- B站公开规范反复要求题文相符、真实性、科学性，并限制夸大、虚假、侵权和不当诱导。
- YouTube 官方创作者资料提供了可迁移的观众体验原则：包装明确表达价值，开头兑现承诺，后续以真实留存曲线观察高点和低点；不能据此声称两个平台算法一致。
- 成熟开源视频 Skill 普遍把需求、脚本、视觉和生成拆成阶段，在昂贵制作前设置脚本确认，并保留可检查中间产物。

完整链接和采用方式见 Skill 的 `references/research-basis.md`。

## 新 SOP

```text
创作者罗盘
  ↓
选题池 → 证据/站内信号 → 选题决策与最小实验
  ↓
标题-封面-开头的统一承诺
  ↓
表达形态选择：知识口播 / Vlog / 脱口秀
  ↓
语气短样校准
  ↓
结构卡 → 逐字稿 → 音画预览 → 桌读与纸面剪辑
  ↓
发布包与单变量实验
  ↓
真实数据复盘 → 下一条的 1–3 个改动
```

## 三种形态的本质区别

| 形态 | 价值来源 | 结构发动机 | 最关键的真实性门禁 |
|---|---|---|---|
| 知识口播 | 解释、证据、判断 | 问题到理解再到应用 | 主张与证据强度匹配 |
| Vlog | 经历、访问、变化 | 目标与过程中的真实转折 | 不把补拍/摆拍冒充抓拍 |
| 脱口秀 | 独特观点、喜剧反差 | 前提的升级、笑点与回扣 | 笑点不靠造谣或伤害弱势 |

## 传播效率的定义

传播效率不是“最大播放量”，而是单位制作成本下，合适受众完成点击、理解、观看、互动和回访的程度。Skill 因此优化四个接口：

- 包装是否准确吸引目标受众；
- 开头是否及时兑现承诺；
- 每个段落是否持续推进价值；
- 发布后是否能从真实数据提炼下一次实验。

这一定义让知识、生活记录和喜剧题材使用同一学习闭环，同时保留各自结构。
