# B站创作者工作台：插件制作计划

## 目标

把现有“视频大纲生成器”升级为可追溯、可选择、可拍摄、可预览、可复盘的创作工作台，服务从新手到稳定更新者的不同阶段。成功标准不是承诺爆款，而是降低错误选题和无效制作成本，让创作者持续获得真实数据并形成自己的表达。

## 阶段与验收

1. **现状审计**：标出现有文件的可保留框架、未经验证规则、缺失能力和风险表述。
2. **外部调研**：优先官方平台资料和一手来源，补充成熟开源 Skill；每条设计结论可追溯。
3. **产品模型**：建立 Explore / Develop / Audit / Retrospect 四种模式，加入创作者优势、受众、资源和边界诊断。
4. **三形态 SOP**：分别定义知识口播、Vlog、脱口秀的叙事发动机、结构、音画需求和风险，用户可在完整写稿前选择。
5. **可调声线**：将语气拆成多维参数，提供短样校准，不模仿具体在世创作者。
6. **交付闭环**：选题研究、包装承诺、结构、逐字稿、音画预览、发布包、复盘均有明确产物和质量门禁。
7. **实现与验证**：主 Skill 保持路由简洁，细节分入 references；提供确定性的时长/占位符检查脚本；通过 Skill 和插件校验，并用三类案例前向测试。

## 不做的事情

- 不把固定时长、固定高潮频率、互动次数或标题公式写成平台算法事实。
- 不伪造实时热度、竞争数据、用户经历、专业资质或引用。
- 不保证播放量、涨粉或商业回报。
- 不在脚本未确认前默认进入高成本分镜或生成环节。

## 版本范围

v0.1.0 聚焦策划与预制作，不直接调用 B站账号、不自动发布、不生成成片。后续版本可在用户明确授权后加入数据导入、模板化项目目录和视觉预览，但不能牺牲来源、隐私与人工确认门禁。
