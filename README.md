# B站创作者工作台

> [打开产品介绍页 / Open the product page](https://yety1113.github.io/bilibili-creator-studio/)

一套面向 Bilibili 创作者的 Codex 插件：从选题验证、表达形态选择和脚本开发，到音画预览、发布包装与数据复盘，把模糊想法推进成真实、可拍、可验证的视频方案。

它不提供“一键爆款公式”，也不会编造平台数据或创作者经历。插件把事实、创作者提供的信息和创作选择分开，帮助你以更低成本完成内容实验。

## 工作流程

`创作者定位 → 选题研究 → 标题封面承诺 → 形态选择 → 节拍表 → 逐字稿 → 音画预览 → 发布包装 → 复盘实验`

你可以只使用其中一个环节，也可以完成整套流程。

## 核心能力

| 模块 | 可以完成的工作 |
| --- | --- |
| 账号与受众 | 梳理创作者优势、目标观众、内容支柱和可持续更新节奏 |
| 选题验证 | 区分真实信号、分析判断与待验证假设，给出推进、缩小、换角度或搁置建议 |
| 内容包装 | 联动设计标题、封面承诺和开场兑现，避免标题与内容脱节 |
| 表达形态 | 比较知识口播、Vlog、喜剧独白，并按素材和制作条件推荐主形态 |
| 脚本开发 | 生成节拍表、可说出口的逐字稿、镜头与声音提示以及时长估算 |
| 发布与复盘 | 准备简介、章节、置顶评论和小型实验，并基于实际数据提出下一轮改进 |

## 三种主要表达形态

- **知识口播**：适合研究、经验、演示和解释型内容。
- **Vlog**：适合过程、地点、挑战、人物关系和真实体验。
- **喜剧独白 / 脱口秀**：适合鲜明观点、矛盾递进、包袱与回扣。

混合形式也可以使用，但插件会先明确主要叙事引擎，避免所有元素互相争抢。

## 安装

克隆仓库后，在仓库根目录运行：

```sh
codex plugin marketplace add .
codex plugin add bilibili-creator-studio@bilibili-creator-studio-github
```

安装完成后开启一个新任务，使插件技能生效。

## 快速开始

从一个想法开始：

> 使用 bilibili-creator-studio，把“普通人如何建立自己的 AI 工作流”发展成一个可拍的 B 站视频方案。先验证选题，再比较知识口播和 Vlog。

审阅已有脚本：

> 使用 bilibili-creator-studio 审阅这份脚本。检查标题承诺、前 30 秒、结构拖沓和难拍镜头，先给修改清单，不要直接重写。

发布后复盘：

> 使用 bilibili-creator-studio 复盘这期视频。我会提供曝光、点击、留存和评论数据，请给下一期最值得测试的三个变化。

## 创作边界

- 不承诺播放量、涨粉或商业结果。
- 不伪造经历、测试结果、平台数据和“真实抓拍”。
- 涉及平台政策、热点、医疗、金融、法律等易变化或高风险内容时，需要重新检索和核验来源。
- 标题、封面与开场应兑现同一个观众承诺，避免误导式包装。
